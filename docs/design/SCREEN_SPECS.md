# j1n.uk URL Shortener — 화면별 레이아웃 스펙

모바일 기준 우선 설계, 데스크톱은 폭 확장 시 규칙만 별도 명시.
토큰 정의는 [DESIGN_TOKENS.md](./DESIGN_TOKENS.md) 참고.
HTML 목업: [mockup.html](./mockup.html) (좌측 상단 탭으로 6화면 전환, 브라우저 폭을 줄이면 반응형 확인 가능)

---

## ① 랜딩 + 생성 화면

**레이아웃**: 상단 로고(중앙) → Hero(H1 "링크를 짧게", 서브카피) → 생성 폼 카드 → 하단 "관리자 로그인" 링크. 최대 폭 480px 중앙 정렬.

**요소**
1. URL 입력 (full width, placeholder: `https://example.com/very/long/link`)
2. "옵션" 접기/펼치기 (기본 접힘)
   - 만료일: 세그먼트/셀렉트 — 없음 / 1일 / 7일 / 30일 / 직접 설정(날짜피커)
   - 비밀번호 보호: 토글 스위치 → on 시 비밀번호 입력 필드 노출
3. Primary CTA "단축하기" (full width)

**상태**
- **빈 화면(기본)**: 입력 없음, CTA는 활성 상태 유지하되 클릭 시 미입력이면 인라인 에러. (관리자 판단: 진입 장벽을 낮추기 위해 비활성화 대신 클릭 시 검증)
- **로딩**: 제출 후 CTA 라벨 "생성 중..." + 스피너, 입력/옵션 비활성화
- **에러**: URL 형식 오류 → 입력 보더 `color-danger` + 하단 헬퍼 "올바른 URL 형식이 아니에요". 서버 오류 → 폼 상단 배너 "일시적인 오류가 발생했어요. 다시 시도해주세요" + 폼은 유지(입력값 보존)

**데스크톱(≥1024px)**: 폭은 480px로 고정, 세로 중앙 정렬 유지(과도한 좌우 확장 없음 — 미니멀 톤 유지)

---

## ② 생성 결과 화면

**레이아웃**: 성공 아이콘 + "생성 완료" 라벨 → 단축 URL 칩(다크, 복사 버튼 내장) → 메타 정보(원본 URL 말줄임, 만료일/비번보호 배지) → QR 코드 카드 → 액션 버튼(복사하기 / QR 다운로드) → "새 링크 만들기"(ghost link)

**반응형**: 모바일 세로 스택. 태블릿 이상(≥640px)에서는 좌측(단축 URL+메타+액션), 우측(QR)의 2열 배치.

**상태**
- **로딩**: 단축 URL 칩과 QR 영역을 스켈레톤(`color-surface-dim` shimmer)으로 표시
- **복사 성공**: 복사 버튼이 일시적으로 체크 아이콘 + "복사됨" (`color-success`)로 전환 후 2초 뒤 원복
- **에러(생성 실패)**: 결과 카드 대신 에러 카드 — 아이콘 + "링크를 만들지 못했어요" + "다시 시도" 버튼(①로 복귀, 입력값 유지)

---

## ③ 관리자 로그인

**레이아웃**: 최대 폭 360px 중앙 정렬 카드. 로고 → "관리자 로그인" 타이틀 → 이메일 입력 → 비밀번호 입력(우측 눈 아이콘으로 표시/숨김 토글) → Primary CTA "로그인" → 하단 "← 홈으로" 링크

**상태**
- **빈 화면(기본)**: 입력 없음
- **로딩**: CTA "로그인 중..." 스피너, 입력 비활성화
- **에러**: 폼 상단 배너 "이메일 또는 비밀번호가 올바르지 않아요"(`color-danger-subtle` 배경) + 두 입력 보더 `color-danger`

---

## ④ 관리자 대시보드

**레이아웃**
- 상단 바: 로고 + "내 링크" 타이틀(좌) / 로그아웃(우, ghost 버튼)
- 액션 행: "+ 새 링크 만들기"(primary, 작게) + 검색 입력(별칭/원본 URL 검색)
- 목록:
  - **모바일**: 카드형 리스트 — 1행(별칭·단축URL + 상태 배지), 2행(원본 URL, 말줄임), 3행(클릭수 · 생성일 · 만료일, `text-small`), 4행(아이콘 버튼: 통계/수정/삭제)
  - **데스크톱(≥1024px, 최대폭 960px)**: 테이블 — 열: 단축 URL | 원본 URL(truncate) | 클릭수 | 생성일 | 만료일 | 상태 배지 | 작업(아이콘)

**상태**
- **빈 화면**: 아직 링크 없음 → 중앙 정렬 일러스트(outline 아이콘) + "아직 만든 링크가 없어요" + CTA "첫 링크 만들기"
- **로딩**: 스켈레톤 행/카드 3~4개 shimmer
- **에러**: 목록 영역에 "목록을 불러오지 못했어요" + "다시 시도" 버튼
- **삭제 확인**: 모달 — "정말 삭제하시겠어요? 되돌릴 수 없어요" + 취소(secondary)/삭제(danger)
- **행 삭제 중**: 해당 행/카드 반투명 처리 + 스피너 오버레이(낙관적 UI)
- **통계 보기**: 행 클릭 또는 통계 아이콘 → 모달/서브패널에 클릭수 요약(총 클릭수, 최근 7일 미니 바 형태) — 상세 차트 구현은 개발 단계에서 결정, 목업은 자리표시 수준

---

## ⑤ 비밀번호 보호 게이트

**레이아웃**: 최대 폭 360px 중앙 정렬 카드. 잠금 아이콘 → "비밀번호로 보호된 링크예요" → 대상 별칭 표시(`text-small`, 회색) → 비밀번호 입력 → Primary CTA "이동하기"(full width)

**상태**
- **빈 화면(기본)**: 입력 없음
- **로딩**: CTA "확인 중..." 스피너
- **에러**: 입력 보더 `color-danger` + 헬퍼 "비밀번호가 올바르지 않아요" (선택: 짧은 shake 트랜지션으로 오답 피드백 강조 — 구현 우선순위 낮음)

---

## ⑥ 만료 / 404 화면

**레이아웃**: 최대 폭 360px 중앙 정렬. outline 일러스트(끊어진 링크/시계 아이콘) → 타이틀 → 서브카피 → CTA

**두 변형**
- **만료됨**: "이 링크는 만료되었어요" + "만료일: YYYY.MM.DD" (`text-small`) + CTA "새 링크 만들기"(①로 이동)
- **찾을 수 없음(404)**: "링크를 찾을 수 없어요" + "주소를 다시 확인해주세요" + CTA "홈으로 가기"

이 화면 자체가 하나의 에러/빈 상태이므로 추가 로딩/에러 하위 상태는 없음.

---

## 공통 규칙

- 모든 폼 제출형 화면은 로딩 중 입력 비활성화 + 버튼 스피너로 중복 제출 방지
- 에러 배너는 항상 폼/리스트 상단에 노출, 사용자의 기존 입력값은 보존
- 삭제류 파괴적 액션은 반드시 확인 모달 경유
- 빈 화면은 항상 다음 행동(CTA)을 함께 제시 — 막다른 화면 없음
